# 记忆闪卡(flashcards)

`.deck.md` 卡组文件 + FSRS 间隔重复复习台 + 一条命令让 Tangu 从当前笔记生成卡组。

手动建卡太慢是闪卡工具的第一痛点——这个插件把「出卡」交给 AI,把「什么时候复习」交给 FSRS,你只负责回答。

> 本仓是 [Forsion](https://github.com/Changan-Su/Forsion)(AI 原生笔记 + 内置 Tangu Agent 的本地优先桌面工作台)的社区插件,捆绑包(bundle)形态:UI 插件 + 随包技能 + 随包 Space,装一处全就位。

## 安装

```bash
git clone https://github.com/Changan-Su/forsion-plugin-flashcards.git
cd forsion-plugin-flashcards
sh install.sh prod    # 安装到 ~/.forsion;开发家用 sh install.sh(默认 dev → ~/.forsion-dev)
```

重启 Forsion 桌面端后生效:命令面板「记忆闪卡:打开复习台」,或工作台侧栏「记忆闪卡」Space。也可整目录压缩为单层 zip 经 Forsion 应用市场安装。

## 功能

- **卡组是一等文件类型**:`.deck.md` 在文件树有专属图标,点击即开卡组编辑视图(就地编辑 Q/A、加卡/删卡、到期统计、「复习本组」)。
- **复习台**(命令面板「记忆闪卡:打开复习台」):跨卡组收集到期卡片,翻面 → 四键评分(重来/困难/记得/简单),按钮上直接预览每档的下次间隔;今日进度条、复习完成庆祝态、空态引导。
- **FSRS-4.5 调度**(精简版,官方默认权重):新卡 Good 次日再见;答错进重学;间隔随稳定度指数增长。调度状态存在卡组文件的 frontmatter `fsrs:` 行里,**手改问题/答案永不影响复习进度**。
- **AI 建卡**(命令面板「记忆闪卡:从当前笔记生成卡组」):把当前笔记全文交给 Tangu,模型返回一个 ```deck 代码块,插件自己解析、分配卡片 ID、写文件——8-20 张原子化卡片,答案短。进度显示在复习台顶部,可随时取消。超长笔记只取前 20000 字并明确提示(不会静默截断)。
- **状态栏「今日待复习」**(1.2.0):全局状态栏一枚常驻项,显示所有卡组合计的今日待复习张数(到期卡 + 今天还允许引入的新卡),点一下打开复习台。复习一张数字就减一(原位更新,不重注册)。清空时显示「闪卡已清空」;还没有卡组、或索引一时读不到时显示中性的「闪卡」——它不会藏起来。
- **到期提醒**(1.2.0,插件设置「启动时提醒到期复习」,默认开):启动后若有到期卡,发一条应用内通知,**一天最多一次**(按本地日期判)。关掉只关通知,状态栏数字照旧;宿主的「按插件静音」照常生效。
- **每日新卡上限**(插件设置,默认 50):到期复习不受限,新卡按上限逐日引入,防止一口气灌爆。
- **成就与活动**:首次复习 / 累计 100 张 / 连续 7 天;每次复习会话结束记一条活动日志。
- **随包技能 `flashcard-format`**:教会 Tangu 该文件格式的全部规则(card 标记、fsrs 行、ID 分配),在聊天里让它直接建/改卡组也不会破坏复习进度。

## 用法

1. **建卡组**:文件树空白处/文件夹上右键「新建卡组」;或打开一篇笔记后运行「记忆闪卡:从当前笔记生成卡组」。
2. **复习**:命令面板「记忆闪卡:打开复习台」。快捷键(复习台内,非全局):`空格`/`回车` 翻面,`1`-`4` 评分。
3. **编辑**:点开任意 `.deck.md`,直接改 Q/A 文本框,自动保存;删卡后新建的卡不会复用旧 ID。

## 数据存哪

- **卡组文件**:你放哪就在哪。右键新建落在所点文件夹;AI 生成与复习台入口新建落在插件「工作文件夹」(插件详情页可改,默认 `记忆闪卡/`)。每张卡的复习状态在文件 frontmatter 的 `fsrs:` 单行 JSON 里——文件即全部,可备份、可同步、可 git。
- **索引**:`<工作文件夹>/.deck-index.json`,只是加速用的目录(卡组名/卡数/到期数/新卡数/下一个到期时刻),自愈:新建/打开/复习都会刷新,文件丢了对应行自动剔除。1.1.x 的老索引缺后两个字段,升级后第一次启动会自动重扫一次补上。**不要手编**。注意:复习台不做全库扫描——**在聊天里让 Tangu 直接写出来的 `.deck.md`(以及移动/改名后的卡组)要在文件树里打开一次才会进入复习队列**;插件建的(右键新建 / AI 生成)自动入列。
- **localStorage**(`plugin.flashcards.*`):`dailyLimit` / `nudge` 设置、当日复习/新卡计数、连击天数。清掉也只影响这几样,不影响卡组与调度状态。
- **插件数据 blob**(`ctx.loadData/saveData`,宿主管的每插件一份 JSON):只存一个 `lastNudgeDate`——今天有没有提醒过。读不到它时插件一次都不提醒(见下)。

## 卡组文件格式(与随包技能一致)

```markdown
---
deck: 高数第三章
fsrs: {"c1":{"due":"2026-08-08T04:00:00.000Z","s":3.2,"d":5.1,"reps":2,"lapses":0,"state":2,"last":"2026-08-06T04:00:00.000Z"}}
---

<!-- card:c1 -->
Q: 洛必达法则的适用条件?(Q 到 A 之间可多行 markdown)
A: 0/0 或 ∞/∞ 型;分母导数不为零;极限存在或为无穷。
```

- 卡片身份 = `<!-- card:cN -->` 标记;新建 ID 取全文最大值 +1(含 fsrs 孤儿键),绝不复用。
- 删卡后残留的 fsrs 孤儿键无害:复习端惰性忽略,插件写文件时自动清理。
- **保真三防线**(手写文件不怕手抖):①标记与 frontmatter 判定宽容(大小写 / 冒号后空格 / 行尾空白 / 开头空行或 BOM / 闭栏 `...`);②插件认不出的内容(首个 card 标记前的正文、`deck:`/`fsrs:` 之外的 frontmatter 键)在重写文件时原样保留;卡片正文里长得像 card 标记的行写盘时自动转义为 `<!-- card\:… -->`,读取时还原。③`fsrs:` 行坏成非法 JSON 时,原始行原样保留、该组暂停复习(编辑器状态栏会提示),绝不重写成 `{}` 抹掉进度。
- 完全不符合卡组格式的 `.deck.md`(没有 frontmatter 也没有 card 标记,多半是改错后缀的普通笔记)打开时进**只读警示态**,停用编辑与自动保存,绝不覆盖原内容。

## 范围说明(明确不做什么)

- **不做系统级 / App 关闭后的推送**:提醒依赖渲染层的定时器,**App 关掉后它不存在,我们承诺不了**。到期卡片下次打开 Forsion 才会提醒你——诚实说明,别指望它叫你起床背单词。
- **不做提醒时间设置、不做多次催促、不做徽章角标**:一天一条通知 + 一枚状态栏数字,就这些。
- **状态栏的数字口径 = 今日待复习**(到期卡 + 今天还允许引入的新卡),**不是「本次复习还剩几张」**:学习步会把刚答错的卡在本节内重排一次,那只影响当前这一节,不进状态栏计数。
- **不为计数而全库扫描**:数字基于插件工作文件夹里的 `.deck-index.json`。从别的设备同步进来(或在聊天里让 Tangu 写出来)的卡组,**打开一次复习台、或在文件树里打开它,就会入账**;在那之前它不在数字里。轮询只读这一个小 JSON,间隔 5 分钟,只有某张卡真的到点了才重扫卡组正文。
- **提醒记录读不到就一次都不提醒**:宿主没有 `loadData/saveData`、或那份 blob 读失败时,插件不会「先提醒了再说」——兑现不了「一天最多一次」就不承诺,也绝不把读不出来的 blob 覆盖掉。
- **不做 Anki 导入/导出**(v2 候选)。
- **不做图片卡**:v1 卡面是纯文本 + markdown(粗体/代码/列表/链接可渲染)。
- **AI 建卡会把当前笔记全文发送到你登录的 Forsion/Tangu 后端**;除此之外一切数据(卡组、进度、索引)都在本地笔记库。
- 复习台与卡组编辑器同时开着(分屏/多窗口)也不怕:编辑器只拥有卡组名与卡片内容,**每次写盘前先读盘,把复习台刚写入的 fsrs 进度合并进来再写**——复习进度不会被编辑器的自动保存回滚。

## 双语(中 / EN)

插件界面跟随 Forsion 的语言设置:宿主切中文就是中文,切 English 就是英文。语言取自 `ctx.getLocale()`,并订阅 `ctx.subscribeLocale` —— **已经打开的复习台与卡组编辑器会原地变**,不用关掉重开。

- **不翻的东西**:卡组名、问题与答案、笔记正文这些是你的数据;卡组文件路径、`localStorage` 键、默认工作文件夹(`记忆闪卡/`)也固定不动 —— 切成英文不该像换了个数据目录。**AI 建卡时模型没给名字的兜底名同理固定为 `未命名卡组`**(和工作文件夹一个口径:落盘的东西不随界面语言变),不是漏翻。
- **英文词表**沿用闪卡产品的通行说法:评分四档 Again / Hard / Good / Easy,卡片状态 New / Learning / Relearning / Due。
- **切语言时正在编辑的草稿不丢**:卡组编辑器会原地重建,但还没过自动保存防抖的文字会带过去,防抖到点照常落盘。代价是**光标与滚动位置会重置**(复习台不受影响,它有还焦逻辑)。
- **已知缺口**:命令面板、斜杠菜单、插件设置页、文件树右键「新建卡组」、成就系列的标题与描述,这些**宿主面**上的文案取的是插件注册那一刻的语言 —— 宿主目前不对贡献点标题做运行时重解析,所以**切换语言后它们要重启 Forsion 才更新**。插件内部的界面不受影响,照样即时切。(插件不会为此自行重注册:那会打断正在进行的 AI 建卡任务和已打开的视图。)
- **状态栏文案与到期提醒实时跟随语言**:它们订阅 `ctx.subscribeLocale` 后经 handle 原位改文案,不用重启也不用重注册。
- **自动化事件目录里的事件名(「完成一轮复习」)只有中文**:宿主的 `PluginEventDecl` 契约只有 `{ name, label }`,没有 `labelEn` 字段可填 —— 要修得先给宿主加接缝,不是插件单方面能解决的。
- 更老的宿主没有 `ctx.getLocale`(2026-08-14 之前)时一律回退中文,不报错。

## 旧宿主兼容

- 缺 `registerFileType`(2026-07-19 之前的宿主):复习台与「打开复习台」命令照常;「新建卡组」「从当前笔记生成卡组」入口隐藏——避免建出会被笔记编译器改写(= 毁档)的 `.deck.md`。
- 缺 `registerView` 的更老宿主:插件整体待命,只弹一条升级提示,不注册任何入口,setup 不抛错。
- `.deck.md` 后缀被内置文件类型接管(`registerFileType` 返回 `false`)时整体退让,只留提示。
- 缺 `ctx.registerStatusItem`(或它返回 void,2026-07-23 之前的宿主):状态栏那一整套不做——不排定时器、不订语言、不提醒,复习台一切照旧。
- 缺 `ctx.loadData/saveData`:不提醒(见范围说明),状态栏数字照常。
- 缺 `registerFileType` 的降级宿主里 `.deck.md` 只是普通笔记:若某个卡组正开在笔记编辑器里,评分会**拒写并跳过这张卡**(整篇覆写会抹掉你正在敲的字),提示你关掉它再复习;这张卡仍留在到期队列里。
- `ctx.notify` / `ctx.achievements` / `ctx.activity` / `ctx.app.workFolder` 缺席时各自静默降级。
